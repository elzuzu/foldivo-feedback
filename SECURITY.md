# Security policy

Do not disclose an exploitable vulnerability, credentials or personal data in a public issue. Use **Security → Report a vulnerability** in this repository to send a private report to the maintainer:

[Report a vulnerability privately](https://github.com/elzuzu/foldivo-feedback/security/advisories/new)

Include the Foldivo version/build and edition, macOS version, reproduction steps with synthetic data, the impact and any proposed mitigation. Do not include real user files or secrets. We will assess reports, but cannot guarantee a response deadline.

Routine bugs and suggestions belong in the public issue forms.
