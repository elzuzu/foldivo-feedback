# Foldivo feedback

Report bugs and suggest improvements for **Foldivo**, the native Apple Silicon file manager for macOS 14 and later. Maintained by **Alex / [elzuzu](https://github.com/elzuzu)**.

This public repository contains user feedback and support documentation only. Application source code, internal audits and app downloads are not hosted here. Availability, compatibility and local pricing are shown on the [Mac App Store product page](https://apps.apple.com/app/id6825317163). The listing is accessible once Apple makes Foldivo available in your storefront.

- [Report a bug](https://github.com/elzuzu/foldivo-feedback/issues/new?template=bug-report.yml)
- [Suggest an improvement](https://github.com/elzuzu/foldivo-feedback/issues/new?template=feature-request.yml)
- [Search existing reports](https://github.com/elzuzu/foldivo-feedback/issues)
- [Support and troubleshooting](SUPPORT.md)
- [Privacy policy](PRIVACY.md)
- [Report a security vulnerability privately](SECURITY.md)

Please write reports **in English** so other users can search and follow them. Include a small reproducible example and your app/macOS versions. In Foldivo, choose **Help → Copy support information**, review the copied text and paste it into your report.

**Issues and attachments are public.** Remove personal paths, names, documents, credentials and account information. Never attach an unreviewed log or a file you do not have permission to share. The app never submits reports automatically.

Foldivo is independent and is not affiliated with Apple or Microsoft. A submitted report does not guarantee a fix or a response time.
