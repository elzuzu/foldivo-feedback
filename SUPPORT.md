# Foldivo support

Use the [bug report form](https://github.com/elzuzu/foldivo-feedback/issues/new?template=bug-report.yml) for unexpected behavior, or the [suggestion form](https://github.com/elzuzu/foldivo-feedback/issues/new?template=feature-request.yml) for improvements. Search existing reports first. Please use English.

## A useful report

Include the app version/build, direct or App Store edition, macOS version, selected interface language, expected behavior and exact reproduction steps. Help → Copy support information copies a limited version/language summary locally; review it before posting. No file paths or logs are attached automatically.

For file operations, reproduce with disposable sample files and describe whether the destination is local, removable, network or cloud-backed. Do not publish personal filenames, file contents or credentials.

## Folder access

In the App Store edition, choose **File → Choose Folder…** and select an authorized folder. macOS privacy permissions and cloud/network providers may still restrict access. Mount a network share in Finder before choosing its folder. To forget remembered access, use **Settings → Folder access → Forget saved folder access**, then quit and reopen Foldivo.

The direct edition offers optional Finder favorite sharing. App Store favorites remain independent.

## Language and region

Choose **Help → Interface language** or the language control in Settings. System language is the default. Foldivo supports English, French, Japanese, Spanish, Korean, Simplified and Traditional Chinese, Brazilian and European Portuguese. Changes apply to Foldivo immediately. Date and number formats continue to follow macOS regional settings; system-owned panels and folder/type names follow macOS.

## Purchases

The Mac App Store edition is not yet on sale. Once available, Apple handles purchases, billing and refund requests. Foldivo has no subscription or in-app purchases.

See [privacy](PRIVACY.md) and [private security reporting](SECURITY.md).
